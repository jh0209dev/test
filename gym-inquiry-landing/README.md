# 헬스장 문의 랜딩페이지 시제품

운동 초보자를 위한 헬스장 소개 페이지와 문의 관리자 화면을 제공하는 로컬 테스트용 정적 웹 시제품입니다.

## 실행

프로젝트 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:4173`을 엽니다.

```bash
python3 -m http.server 4173
```

관리자 화면은 `http://localhost:4173/admin/`에서 확인할 수 있습니다. 시제품 비밀번호는 `1234`입니다.

## 주요 파일

- `index.html`: 방문자용 랜딩페이지와 문의 폼
- `admin/index.html`: 관리자용 문의 목록 화면
- `js/`: 문의 저장 및 화면 동작
- `styles.css`: 반응형 화면 스타일
- `assets/`: 시제품에 사용하는 이미지
- `PRD.md`: 제품 요구사항과 확인 시나리오
- `.agents/skills/tdd/`: 프로젝트 전용 TDD 스킬 안내

## 시제품 범위

문의는 브라우저 `localStorage`에 저장되며, 입력한 브라우저와 사이트 주소에서만 볼 수 있습니다. 서버 전송, 이메일 알림, 기기 간 동기화는 구현되어 있지 않습니다. 실제 고객 정보를 입력하지 마세요.

관리자 비밀번호 `1234`는 화면 확인용 잠금이며 실제 인증 수단이 아닙니다. 공개 운영 전에는 서버 저장소와 안전한 관리자 인증을 적용해야 합니다.

헬스장 이름, 주소, 운영시간, 시설, 프로그램 등 미확정 정보는 실제 운영 정보에 맞게 바꿔야 합니다.
